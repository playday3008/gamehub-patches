# 🧩 GameHub Patches

![GitHub Workflow Status (with event)](https://img.shields.io/github/actions/workflow/status/playday3008/gamehub-patches/release.yml)
![GPLv3 License](https://img.shields.io/badge/License-GPL%20v3-yellow.svg)

ReVanced Patches for [GameHub](https://www.gamehubglobal.com/) (`com.xiaoji.egggame`).

## ❓ About

This repository contains patches for GameHub, built using the [ReVanced Patcher](https://github.com/ReVanced/revanced-patcher).
Patches from this and other repositories can be used together with [ReVanced Manager](https://github.com/ReVanced/revanced-manager) or [ReVanced CLI](https://github.com/ReVanced/revanced-cli).

## 🧑‍💻 Usage

To use these patches, add this repository as a patch source in [ReVanced Manager](https://github.com/ReVanced/revanced-manager) or use them directly with [ReVanced CLI](https://github.com/ReVanced/revanced-cli).
